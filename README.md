# Pomodoro Clock ⏰🍅

A simple **Pomodoro Clock** application built with **Python** and **PySide6**.
This project works as both a **real-time digital clock** and a **Pomodoro timer**, helping users manage focus and break sessions.

---

## 📌 Features

- Real-time digital clock (HH:MM:SS)
- Pomodoro timer options:
  - 25 minutes (standard Pomodoro)
  - 50 minutes (extended focus session)
  - 5 minutes break
- Simple and clean graphical interface
- Built using PySide6 (Qt for Python)

---

## 🧠 How It Works

- When the application starts, it displays the current system time.
- Clicking one of the Pomodoro buttons starts a countdown timer.
- While the countdown is active, the clock switches to **timer mode**.
- When the timer reaches zero, the application returns to **clock mode** automatically.

---

## 🛠 Technologies Used

- Python 3
- PySide6 (Qt for Python)
- QTimer for time control
- QGridLayout for interface layout
